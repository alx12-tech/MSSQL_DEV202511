 # Описание содержимого папки

 ## Назначение

 Папка содержит материалы проекта по курсу MSSQL Developer

 ## Структура

 | SubFolder |Описание|
 |-----------|--------|
 |DBStruct  | скрипты БД (создания структуры, объектов, процедур, обслуживания) |
 |Reports   | скрипты отчётов (витрин, представлений)|
 |Pics      | набор изображений для включения в документацию |
 |ТЗ        | Материалы технического задания и для технического задания, презентация (если будет)|


 ## Структура папки DBStruct:

 ### Папки

 * DB_Backup - полный бэкап базы с тестовыми данными
 * original_files - оригинальные файлы (скрипты создания таблиц, процедур, функций..)

 ### Файлы
 * FULL_BASE PersonalFinance_v4_entire.SQL - выгруженный из БД скрипт создания элементов БД
 * Скрипт TEST_FCT_CARRY_generator.sql - генератор тестовых данных, размещает даннные в слое stage
 * Скрипт DM_REST_historical_upload.sql - скрипт для загрузки тестовых данных в расчётный слой
 * Скрипт Выгрузка ОСВ.sql - скрипт выгрузки ОСВ (не оформлялся в процедуру - используется как пользовательский запрос)
